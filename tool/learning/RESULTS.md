# 미션 학습 오프라인 평가 (simulate.py)

실행: `pip install numpy` 뒤 `python simulate.py` (약 1~2분), 값 고르기 `python tune.py`, 테스트 기대값 `python expected.py`

가상 사용자 7명 × 200번, 한 사람이 상대 3명을 차례로 (상대마다 D-27, 학습은 이어짐)
정책: rules 지금 앱 · today 오늘의 미션만 학습 · full 오늘의 미션 + 주차 구성 학습 (앱에 넣음)
      · crush full + 상대 층 · oracle 진짜 완료 확률을 앎 (위쪽 한계)
굵은 숫자: 규칙 대비 차이 (%p)

## 결론
- 주차 구성까지 배워야 효과가 남 (today만으로는 거의 그대로)
- 선호가 뚜렷한 사람(온라인파)은 상대가 바뀌어도 이어 배워서 갈수록 좋아짐 (상대1 0.60 → 상대3 0.70)
- 규칙대로형 · 저녁형 · 용감형 · 조심형 · 주말형은 규칙과 ±1%p 안 (큰 손해 없음)
- 상대 층은 효과 없음 (상대 한 명당 기록이 20~30개라 못 배움) → 앱에는 '나' 모델 하나만
- 상대마다 선호가 반대인 사람은 거의 그대로 (-0.1%p), 상대 층으로도 못 가름
- 주차 구성은 완료 기록 5개부터 학습 순서 + 주차마다 쉬운 미션(용기 최대보다 한 단계 아래) 최소 1개
  (넣기 전과 비교한 완료율: 온라인파 +5.6 → +5.9, 상대마다 다름 -0.7 → -0.2, 주말형 +0.9 → +1.4,
   용감형 +1.7 → +1.4, 규칙대로형 +1.5 → +0.1 (처음 몇 주를 지금 순서로 고르니 규칙과 거의 같아짐))
- 미션 고르기 규칙을 '용기 이하 아무거나' → '용기에 딱 맞는 것부터'로 바꾼 뒤 (2026-11-28) 다시 잼
  규칙만 쓸 때 완료율: 용감형 0.794 → 0.850, 규칙대로형 0.827 → 0.850, 온라인파 0.680 → 0.605 (대면 · 어려운 미션이 늘어서)
  학습(full)은 온라인파 +5.9 → +9.4 (규칙이 놓친 걸 더 많이 되찾음), 용감형 +1.4 → -0.5 (규칙이 이미 맞춰 줌)
- 미션이 밀리면(진도 늦음) 다음 주부터 한 단계 늦추기를 넣은 뒤 (2026-11-28) 다시 잼
  규칙만 쓸 때 완료율: 주말형 0.599 → 0.623, 상대마다 다름 0.418 → 0.428, 조심형 0.815 → 0.801, 온라인파 0.605 → 0.563
  (늦춘 단계에 대면 미션이 많아 온라인파는 손해, 시뮬레이션은 '못 했어요'로 바꾸기 · 부담이 줄어드는 효과는 없음)
  학습(full) 대비: 온라인파 +10.2, 그 외 ±1%p 안
- 오늘의 미션을 보고도 안 한 날에 약한 −를 주거나 보상 크기를 바꿔도 차이 없음 → 안 씀 (tune.py)

## 멘트 (simulate_lines.py)

가상 사용자 4명 × 300번, 대화 분석 10번 (방향 · 주제 · 시각 무작위), 실제 멘트 사전과 같은 단어 사전으로 멘트 표시
- 선호가 뚜렷하면 첫 화면 복사율이 오름 (짧게형 +8.3%p, 다정형 +3.8, 질문형 +2.7), 아무거나형은 그대로
- '↻'에 복사 안 한 줄마다 약한 −(−0.03 ~ −0.3)를 주면 오히려 나빠짐 → 안 씀 (복사 +1만)
- 탐색 세기 0.15, 표시 · 길이 λ 2, 나머지 λ 6
