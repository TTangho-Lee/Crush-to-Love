# 💌 DueDate · 듀데이트

**"종강까지 20일. 첫마디는 오늘."**

[🌐 웹에서 바로 쓰기](https://ttangho-lee.github.io/Crush-to-Love/) · [📱 안드로이드 APK 받기](https://github.com/TTangho-Lee/Crush-to-Love/releases/download/v1.0.0/DueDate-v1.0.0.apk)

## 💡 프로젝트 소개 (Overview)

『듀데이트 (DueDate)』는 종강, 군 입대, 졸업, 이직 등 명확한 유효기간(Due Date) 안에 목표한 관계 진전을 이룰 수 있도록 돕는 **유효기간 기반 짝사랑 공략 & 대화 코칭 앱**입니다.

기존 연애 서비스가 '이미 관계가 형성된 커플용 앱'이거나 '불특정 다수 매칭(소개팅)'에 편중되어 있었다면, 듀데이트는 "언제, 어떻게 다가가야 할지 몰라 타이밍을 놓치는 대학생 및 청년층의 짝사랑"에 집중합니다. 현실의 연애는 `Ctrl+Z`로 되돌릴 수 없기에, 말 한마디 못 걸어보고 유효기간을 넘기는 후회나 섣부른 접근으로 관계를 망치는 실수를 줄이고자 기획되었습니다.

남은 날짜(D-Day), 현재 친밀도, 만남 빈도, 사용자의 심리적 준비도인 '용기 배터리', 그리고 카톡 대화 분석을 종합해 오늘 당장 실행할 수 있는 현실적인 행동 미션과 건넬 말 한마디를 제안합니다.

그리고 이 모든 추천은 **쓸수록 나에게 맞춰집니다.** 사용자의 선택을 기기 안에서 학습해, 같은 상황이라도 사람마다 다른 추천을 내놓습니다.

## 🏁 목표

- **서비스(기획) 목표:** 현실에서 `Ctrl+Z` 할 수 없는 짝사랑 타이밍을 놓치지 않도록, 유효기간과 현재 관계 온도에 맞춘 단계별 공략 가이드 제공.
- **기술적 목표:** 사용자 상태 변수(남은 일수, 친밀도, 만남 빈도, 용기 배터리)와 대화 분석 결과에 따라 로드맵을 다시 짜는 알고리즘, 그리고 서버 · 외부 AI 없이 **기기 안에서만** 대화를 분석하고 추천을 학습하는 개인정보 친화적 구조 구현.

## 🗝️ 핵심 가치: Right Timing, Right Words — Private by Design, Personal by Learning

**"남은 시간과 용기 배터리에 맞춰 오늘 건네는 단 한마디"**

- 🔋 **심리적 장벽을 낮추는 게이미피케이션 (용기 배터리):** 어려운 미션을 강요하지 않고 지금 용기(0~100%, 저전력 · 표준 · 고속충전 · 풀충전)에 딱 맞는 미션부터 고릅니다. 같은 D-20이라도 얼굴만 아는 사이라면 가벼운 눈인사부터, 이미 연락하는 사이라면 약속 잡기부터 시작하고, 진척도도 그만큼 앞에서 시작합니다.
- 🔄 **상황 변화에 유연한 동적 로드맵:** 미션을 못 해도 감점하지 않고 더 쉬운 미션으로 바꾸거나 넘길 수 있으며, 진도 · 대화 분석에 맞춰 다음 주차를 자동으로 당기거나 늦춥니다. 관계가 바뀌면 완료 기록은 그대로 두고 남은 주차만 다시 짭니다.
- 🔒 **대화는 기기 안에만:** 짝사랑 대화는 가장 민감한 데이터입니다. 카톡 원문은 저장하지도 외부로 보내지도 않고, 분석에서 나온 숫자만 기기에 남깁니다. 앱에 API 키도 없습니다.
- 🧠 **쓸수록 나에게 맞춰짐:** 정해진 규칙으로 시작하지만, 어떤 미션을 해냈는지, 어떤 멘트를 복사했는지, 다음 대화에서 호감 신호가 어떻게 변했는지를 학습해 추천 순서가 사람마다 달라집니다.

## 🖥️ 개발 방식 및 기술 스택

### 🛠️ Tech Stack

- **Framework:** Flutter (Dart ^3.14, `material_ui`) — Android · iOS · Web
- **State:** `ChangeNotifier` + `InheritedNotifier`
- **Storage:** `sqflite` / `sqflite_common_ffi_web` (기기 안 SQLite, 서버 없음) — 기능마다 DB 분리 (`profile.db` · `roadmap.db` · `chat_history.db` · `learning.db`)
- **Analysis:** 규칙 기반 카톡 대화 분석 파이프라인 (외부 AI · LLM 호출 없음)
- **Recommendation:** Contextual Bandit (베이지안 선형 회귀 + Thompson Sampling), Dart 직접 구현
- **Evaluation:** Python + numpy (가상 사용자 시뮬레이션 · 테스트 기대값)
- **etc.:** `file_picker`(txt 불러오기), `flutter_local_notifications` · `timezone`(D-Day 알림)
- **Design & Collaboration:** Figma (Low-Fatigue & Non-AI 플랫 디자인 시스템), GitHub, Notion

## 🕹️ 주요 기능 및 구현

### ① 🧭 유효기간 · 관계 맞춤 온보딩 & 미션 로드맵

1분 안에 끝나는 스텝 카드로 지금 상황을 진단하고, D-Day까지의 주차별 행동 미션 로드맵을 자동으로 만듭니다.

- **5대 핵심 지표 반영:** 유효기간(D-Day 및 사유 태그), 현재 친밀도(얼굴만 · 스몰토크 · 사적 연락), 주간 만남 빈도, 용기 배터리, 최종 목표(친해지기 / 썸 타기 / 사귀기).
- **상황 맞춤 미션:** 사이에서 시작해 목표에서 멈추는 8단계(인사할 틈 → 이야기할 거리 → … → 마음 전하기), 미션 67개. 지금 용기에 딱 맞는 것 → 한 단계 아래 → 더 쉬운 것 순으로 고르고, 만남이 없으면 만나야 하는 미션은 뺍니다.
- **이번 주 미션:** 미션을 한 줄씩 접어 두고, 누른 미션만 펼쳐 용기 · 방법 · 팁을 보여 줍니다. 체크 칸으로 바로 완료 · 취소하고, 완료하면 바로 아래 미션이 펼쳐집니다. 이번 주를 다 하면 다 한 주차는 한 줄(✓)로 접히고 다음 주 미션을 미리 할 수 있습니다.
- **못 했어요:** 감점 없이 같은 단계의 더 쉬운 미션으로 바꿔 주고, 같은 자리에서 두 번 바꾼 뒤에는 ✕로 닫고 넘어갑니다 (더 어려운 미션으로 올라가지 않음).
- **진척도:** 뒤 단계 · 어려운 미션일수록 크게 오르고, 지금 용기보다 어려운 미션을 해내면 1.5배. 이미 가까운 사이면 지나온 단계만큼 채운 채 시작합니다 (예: 사귀기 목표 — 얼굴만 0% · 스몰토크 5% · 사적 연락 32%).
- **여러 상대 관리:** 짝사랑 상대를 여러 명 등록하고 머리글에서 전환 · 보관 · 삭제할 수 있습니다.
- **D-Day 알림:** D-3 · D-1 저녁에 알려 줍니다. 알림 글자에는 상대 이름을 넣지 않습니다.
- ⚙️ 구현 기술:
    - **동적 로드맵 산출:** 남은 일수를 7일 단위 주차로 나누고 친밀도 → 목표 단계를 주차에 분배 (`roadmap/roadmap_generator.dart`).
    - **자동 조정:** 진도가 빠르거나 대화 분석으로 본 사이가 가까우면 다음 주차부터 한 단계 당기고, 미션이 밀리거나 반응이 조심스러우면 늦춤, 따라잡으면 원래 속도로 (`roadmap/roadmap_rules.dart`).
    - **'못 했어요':** 로드맵에 없고 그 주차에서 뺀 적 없는 미션 중 그보다 어렵지 않고 용기에 가까운 것으로 교체, 뺀 미션은 주차에 기억해 다시 안 고름 (`replaceMission`).
    - **'우리 사이 업데이트':** 친밀도 · 목표 · 용기가 바뀌면 끝난 주차와 완료한 미션은 보존하고 남은 미션만 다시 계산.
    - `onboarding/data/crush_store.dart`: 상대 목록 · 내 용기를 `profile.db`에 저장, 버전이 바뀌어도 기존 데이터를 그대로 옮김.

### ② 💬 대화 피드백 & 썸 판독기

카톡에서 내보낸 txt를 불러오거나 붙여넣으면, AI 없이 규칙만으로 대화 흐름을 분석합니다.

- **호감 신호 점수:** 답장 속도, 먼저 말을 건 비율, 되묻기, 웃음 · 칭찬 표현 등을 종합해 0~100점과 근거를 보여 줍니다.
- **다음 대화 추천:** 지금 사이를 추정하고, 18가지 방향(약속 제안 · 질문 주고받기 · 오랜만에 연락 등) 중 하나와 예시 멘트를 추천합니다. 자주 나온 주제가 있으면 그 주제로 멘트를 고릅니다.
- **내 말투 맞추기:** 대화 속 내 메시지에서 ㅋㅋ · ㅎㅎ 쓰는 정도와 존댓말 여부를 읽어 추천 멘트 말투를 맞춥니다.
- **기록:** 상대별 호감 점수 변화를 모아 보여 주고, 분석 결과는 미션 로드맵 조정에도 쓰입니다.
- ⚙️ 구현 기술:
    - `analysis/chat/rules/`: 정리 → 단어 사전 표시 → 주고받기 지표 → 점수 → 추론 → 멘트 · 말투의 단계별 규칙 파이프라인.
    - 멘트 사전 약 2,800줄, 대화 원문은 저장하지 않고 숫자만 `chat_history.db`에 기록.

### ③ 🎯 데이트 완벽 준비 코칭

장소 · 날씨 · 시간 · 인원을 고르면 실전 데이트 가이드를 한 번에 보여 줍니다.

- **가이드:** 복장(OOTD) · 데이트 코스 동선 · 추천 메뉴 · 대화 소재 · 분위기, 용기 배터리에 맞춘 **한마디 팁**, 만난 뒤 보낼 **애프터 톡**.
- **대화 분석 연결:** 대화 분석에서 자주 나온 주제가 있으면 어울리는 장소를 미리 골라 두고, 그 주제로 대화 소재를 만듭니다.
- ⚙️ 구현 기술:
    - `analysis/date/`: 조건마다 문장 사전(약 1,200줄)에서 고르고, 사이 · 용기 · 목표에 맞춰 한마디 팁의 수위를 조절.

### ④ 🧠 쓸수록 나에게 맞춰지는 추천 (기기 안 학습)

규칙으로 시작해서 **사용자의 선택으로 학습하는** 추천 엔진입니다.

- **배우는 신호:** 미션 완료 · 완료 취소 · '못 했어요' · 주차가 끝날 때까지 안 한 미션, 예시 멘트 복사, 다음 대화 분석에서 호감 점수가 바뀐 만큼(늦게 오는 보상), 짝사랑 결과(성공 · 실패).
- **추천하는 것:** 오늘의 미션 · 주차 미션 구성, 대화 분석 예시 멘트 순서, 데이트 가이드의 한마디 팁 · 대화 소재 질문 · 만난 뒤 톡.
- **안전장치:** 상대 반응이 조심스러우면 과감한 행동을 1순위로 올리지 않는 등, 학습이 넘지 못하는 규칙을 둡니다. 학습을 끄면 규칙 그대로 동작합니다.
- **사용자 제어:** 설정 › 학습한 내용에서 기록 수 · 잘 해낸 미션 · 잘 안 한 미션 · 자주 고른 멘트를 보고, 학습을 끄거나 기록을 지울 수 있습니다.
- ⚙️ 구현 기술:
    - `learning/linear_ts.dart`: 베이지안 선형 회귀 + Thompson Sampling. 기존 규칙 점수를 사전 평균으로 넣어, 처음엔 규칙과 같게 시작하고 기록이 쌓일수록 개인화.
    - `learning/learning_db.dart`: 사건 기록만 쌓고 모델은 언제든 다시 계산 → 상대를 지우면 그 상대에게서 배운 것도 정확히 지움.
    - 웹 · Python과 같은 값을 내도록 32비트 난수(xorshift32)를 직접 구현해 테스트 기대값을 맞춤.
    - 미션: 완료 기록 5개가 쌓인 뒤부터 주차 구성을 학습 순서로 고르고, 주차마다 쉬운 미션을 최소 1개 넣음.

#### 📈 오프라인 평가 (가상 사용자 시뮬레이션)

실제 사용자 데이터 없이 학습 효과를 확인하려고, 앱이 모르는 **숨은 취향**을 가진 가상 사용자를 만들어 실제 앱 규칙 그대로 돌려 봤습니다.

- **가상 사용자 7명:** 온라인파(직접 만나는 미션을 꺼림) · 저녁형 · 용감형 · 조심형 · 주말형 · 규칙대로형 · 상대마다 다름. 미션을 할 확률은 숨은 취향 · 용기보다 어려운 정도 · 시간대 · 상대 반응으로 정해집니다.
- **하루 흐름:** 앱을 열지 정함 → 오늘의 미션을 보고 할지 정함 (안 내키면 넘김) → 가끔 하나 더. 연락 미션을 하면 상대의 '따뜻함'이 오르고, 7일마다 대화 분석(호감 점수)으로 로드맵을 조정합니다.
- **비교:** 같은 사용자 · 같은 난수로 규칙만(rules) / 학습(full, 앱에 넣은 것) / 정답을 아는 경우(oracle, 상한)를 비교. 사람마다 상대 3명(27일씩) × 200번.
- **앱과 같은 규칙:** 앱 규칙을 Python으로 옮긴 `dart_rules.py`가 앱의 미션 사전을 직접 읽고, Dart 테스트로 둘의 결과가 같은지 확인합니다.

| 미션 완료율 | 규칙만 | 학습 | 차이 |
|---|---|---|---|
| 온라인파 | 0.563 | 0.665 | **+10.2%p** |
| 조심형 · 주말형 | 0.801 · 0.623 | 0.807 · 0.627 | +0.6 · +0.4%p |
| 저녁형 · 용감형 · 규칙대로형 · 상대마다 다름 | | | −0.9 ~ −0.1%p (손해 거의 없음) |

| 예시 멘트 첫 화면 복사율 | 규칙만 | 학습 | 차이 |
|---|---|---|---|
| 짧게형 | 0.249 | 0.332 | **+8.3%p** |
| 다정형 · 질문형 | 0.167 · 0.278 | 0.205 · 0.304 | +3.8 · +2.7%p |

> 선호가 뚜렷한 사람일수록 크게 좋아지고, 선호가 없거나 규칙과 같은 사람은 거의 그대로입니다. 숨은 취향은 직접 정한 가정이라 실제 사용자에서의 효과를 보장하지는 않습니다. 전체 표 · 방법: [`tool/learning/RESULTS.md`](tool/learning/RESULTS.md)

### ⑤ 🏳️ D-Day 이후: 결과와 돌아보기

D-Day가 지나면 결과를 묻습니다. 성공하면 축하와 함께 데이트 기능을 이어서 쓰고, 실패하면 스스로 부족했던 점을 적어 보며 돌아봅니다.

- ⚙️ 구현 기술:
    - `outcome/reflect_rules.dart`: 쓴 글을 단어 사전으로 분석해 용기 · 답장 · 적극성 · 성격 중 부족했던 점을 찾고, 글에서 못 찾으면 용기 배터리 · 대화 분석 기록으로 보완. 쓴 글은 저장하지 않음.

## 💰 실용성 및 확장성

짝사랑 고민은 누구나 겪지만, 대화 내용이 민감해 외부 서비스에 맡기기 어렵습니다. 듀데이트는 **대화가 기기 밖으로 나가지 않는다**는 점을 기본으로 삼아, 가장 사적인 고민에 안심하고 쓸 수 있는 도우미를 지향합니다.

정해진 D-Day라는 분명한 시간 제약은 "언젠가"가 아닌 "오늘"의 행동을 끌어내고, 학습하는 추천은 오래 쓸수록 더 정확해져 사용자가 계속 돌아올 이유를 만듭니다.

앞으로 가상 사용자로 미리 학습한 초기 모델을 앱에 넣어 처음부터 더 나은 추천을 주고, 기기 안에서 도는 작은 언어 모델로 대화 표현 분석을 고도화할 계획입니다.

## 📁 프로젝트 구조

```
lib/
├─ main.dart              앱 시작, 저장소 불러오기 · 연결
├─ app/                   앱 틀(하단 탭), 테마, 설정, 상대 전환, 알림, 학습한 내용
├─ onboarding/            시작 · 5단계 온보딩, 상대 목록 저장(profile.db)
├─ roadmap/               미션 흐름: 홈(진척도 · 오늘의 미션) · 로드맵 · 주차 상세 · 우리 사이 업데이트 (roadmap.db)
├─ mission/               미션 흐름 팀원 버전 (작업 중)
├─ analysis/
│  ├─ chat/               카톡 읽기 → 표시 → 지표 → 호감 점수 → 추론 → 멘트 · 말투 (chat_history.db)
│  └─ date/               데이트 준비 · 가이드
├─ learning/              맞춤 추천 엔진 (Thompson Sampling, learning.db)
├─ outcome/               D-Day 이후 결과 · 돌아보기
└─ shared/                공통 데이터 · 색(#F4BEAE · #F2DCDB · #FFFDFC 등) · 위젯
test/                     단위 · 위젯 테스트
tool/learning/            시뮬레이션 · 오프라인 평가 (Python)
```
